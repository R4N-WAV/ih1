## 5. Competing approaches and trade-offs found

- **Pitch engine:** period-synchronous TD (latency ~1–2 periods, formants kept, monophonic only) vs Laroche–Dolson spectral shifting (frame latency ~20–45 ms, polyphonic, **N voices at fixed cost**, formant control via true envelope). *Choice:* spectral for Harmony/Pitch/Formant/Shimmer. TD cycle-repeat for the low-latency Pitch Correction mode.
- **Delay time changes:** length-type (clean, crossfade, no pitch) vs speed-type (tape/BBD pitch bends). *Choice:* length-type for Delay, speed-type for Tape Echo. This is the clean-Delay vs Tape-Echo distinction the brief requires.
- **Reverb:** Dattorro plate (tuned by ear, cheap, fixed character) vs FDN (designable T60 per band, scalable density). *Choice:* both as Reverb modes.
- **Antialiasing:** measured table in `KNW-MCXD9ZQP83`. *Choice:* ADAA-1 + 2× OS default, 4× HQ (latency reported, applied on re-activation).
- **Framework:** JUCE wrapper + JUCE-free engine (Isai precedent) vs raw VST3 SDK. See `docs/OPEN_DECISIONS.md` A1.
