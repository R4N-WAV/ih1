# Factory preset index (V3)

67 read-only factory presets, defined as data in `core/src/presets/Presets.cpp`: **Init** (the clean empty state) and 5 utility / enhancement presets, then 61 creative sound-design presets in ten categories. Every preset is an original IH1 design (no names, settings or assets from any commercial product). Measurements of every preset on its tagged sources: `docs/V3_PRESET_AUDIT_TABLE.md` (generated by `tools/ih1_preset_audit`).

The preset arrows walk this order and wrap; user presets (*User*) follow. Selecting any preset lands the FX wheel on **None** (the staged FX is deselected; its settings stay cached).
